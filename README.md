# GovTech Issue Gateway Simulator

A civic tech web application built with HTML5, CSS3, and Vanilla JavaScript that simulates automated incident priority routing for municipal service management.

## 🚀 Features

* **Citizen Report Intake:** Allows residents to submit civic feedback, specify locations, and categorize infrastructure issues.
* **Smart Priority Routing Engine:** Automatically scans incident descriptions for keyword triggers (e.g., *leak*, *fire*, *broken*) to instantly flag critical emergencies and push them to the top of the dispatch queue.
* **Government Dispatch Console:** Route verified incident payloads to different municipal agency endpoints (PUB, LTA, HDB, NEA, or Town Councils).
* **Archived Log Table:** Keeps track of all transmitted dispatches with real-time success statuses.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Tailwind CSS)
* **Logic:** Vanilla JavaScript (ES6+ Array Methods & Sorting Algorithms)
